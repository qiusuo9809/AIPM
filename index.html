Part 01

AI Agent 层级框架

从被动问答到完全自主，Agent 的能力跃迁定义了行业的竞争格局。

L1
被动问答
用户发起提问，Agent 即时响应。典型代表：ChatGPT 基础对话、Siri 问答。
人在场 · 即时响应
L2
工具调用
Agent 可调用外部 API、执行代码、操作文件。用户仍需在场确认和触发。
人在场 · 需触发
L3
持续运行（主动化）
Agent 在后台持续工作，主动推送结果。人不在场时仍在执行——这是当前行业大战的关键跨越。
人可不在场 · 主动推送
L4
完全自主
Agent 自主设定目标、规划路径、自我迭代，人类仅需设定高层意图。
终极目标 · 自我驱动

L2 → L3 是当前行业大战的关键跨越。核心判断标准：人不在场时，Agent 是否仍在工作。

Part 03

L3 三大技术壁垒

从 L2 跨越到 L3，需要在三个核心技术维度上取得突破。

01
持久化状态
Agent 需要记住跨会话的上下文、用户偏好和任务进度。状态丢失意味着每一次交互都是"从零开始"。
02
异步执行架构
从同步请求-响应模式转向异步事件驱动。任务可以在后台排队、调度、重试，而不阻塞用户当前操作。
03
信任与权限边界
Agent 在无人监督时执行操作，需要细粒度的权限控制、可审计的操作日志，以及用户可撤销的安全机制。

企业场景天然适合 L3
B2B 场景对"后台运行"有天然需求：数据同步、定时报告、监控告警。企业愿意为持续运行的 Agent 付费。

已有工具调用能力，仅需补充事件触发机制（定时、Webhook、数据变更）即可实现 L3 跨越。

供应链
交货期异动预警

供应商交期一旦延迟，采购经理靠人工电话确认，往往发现时已影响排产。Agent 持续监控进度节点，提前预警并自动起草催货邮件，节省大量跟单人力。

触发逻辑：进度落后 → 推送 + 催货邮件草稿
